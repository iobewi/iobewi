# Roadmap

The roadmap is intentionally capability-oriented rather than tied to permanent S-numbers.

1. Workload capability model and first hardware-facing capabilities.
2. Real-time execution and scheduling model, including explicit multicore/preemption
   boundaries where required.
3. Resource/capability ownership and, if justified, hardware memory protection.
4. Second native hardware platform to prove source/API portability.
5. Broader Core orchestration and product integration.

The Architecture Knowledge Baseline precedes new functional development so each future
change can be handed to a fresh agent using repository knowledge alone.
